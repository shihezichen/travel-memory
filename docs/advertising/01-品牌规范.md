# 01 · 品牌规范

## 视觉 tokens（取自官网 `:root` CSS，2026-09-16 实测）

```css
--bg:          #0A0A0C      /* 主背景，近黑 */
--bg-soft:     #101014      /* 次级背景 */
--line:        rgba(255,255,255,.09)
--line-strong: rgba(255,255,255,.16)
--fg:          #FFFFFF
--fg-2:        rgba(255,255,255,.66)   /* 正文次级 */
--fg-3:        rgba(255,255,255,.42)   /* 说明文字 */
--brand-1:     #FF8A00      /* 品牌橙 */
--brand-2:     #F5296E      /* 品牌玫红 */
--grad:        linear-gradient(120deg, var(--brand-1), var(--brand-2))
--r:           18px
--maxw:        1140px
```

**风格基调**：深色科技风。近黑底 + 橙→玫红渐变作为唯一强调色；标题用渐变字，正文用白色不同透明度分层；卡片圆角 18px、细描边、无明显阴影。

## 字体

官网字体栈：
```
-apple-system, BlinkMacSystemFont, "SF Pro SC", "PingFang SC",
"Microsoft YaHei", "Helvetica Neue", Arial, sans-serif
```
- 视频字幕/落版建议：**思源黑体 / 苹方 / 微软雅黑 Bold**（Windows 上 `C:\Windows\Fonts\msyhbd.ttc`）
- 英文品牌名用无衬线（Inter / SF Pro / Helvetica）

## Logo

- 站点图标：`https://top001.xin/static/icon.svg` → 已存 `assets/icon.svg`
- 组合署名：**旅行记忆 · Travel Memory**
- 用法：右下/左下角常驻小尺寸，或落版居中放大；背景必须深色或加暗色蒙版

## 品牌名与写法

- 中文：**旅行记忆**
- 英文：**Travel Memory**（首字母大写，中间空格）
- 对外不缩写、不翻译成 "TravelMemory"

## 视频规格（横屏主片）

| 项 | 值 |
|---|---|
| 画幅 | 1920×1080（16:9），母版可出 3840×2160 |
| 帧率 | 30fps |
| 编码 | H.264 High / yuv420p / `+faststart`（网页可秒播） |
| 音频 | AAC 192kbps 立体声，混音响度 ≈ **-16 LUFS** |
| 屏幕录制 | CDP screencast 采集，**只拍页面内容，不含任何浏览器边框/地址栏/窗口装饰** |
| 字幕 | 中文，底部居中，白字 + 半透明黑底，字号 38px（1080p） |

## 音色与音乐

- 旁白：`edge-tts` 中文女声（v1 用 `zh-CN-XiaoxiaoNeural`），语速 +8%，听感自然偏温
- 备选男声：`zh-CN-YunxiNeural`（年轻男声，适合"激情"方向）
- 音乐：v1 为程序合成的柔和垫乐；**v2 要求换成"有记忆点 / 有动感节奏 / 有激情"的曲风**，且必须**无版权风险**
