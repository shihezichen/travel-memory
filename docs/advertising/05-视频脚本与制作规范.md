# 二、v2 制作规范（刚哥 2026-09-16 下达）

> 目标：**50 秒横屏**（1920×1080）宣传片 v2，在 v1 基础上做四点升级。

| # | 要求 | 落地做法 |
|---|---|---|
| 2.1 | **配乐**：有记忆点 / 有动感节奏 / 有激情 | 换掉 v1 的柔和垫乐。用有清晰动机（motif）的节奏型 BGM：稳定的 4/4 脉冲（kick + 军鼓/拍手）、8 分音符琶音动机、中段 build-up、落版处一次收束重击。BPM ≈ 100–110 兼顾"激情"与"讲述"。人声间隙保留、副歌处抬升。**必须无版权风险**（自生成或 CC0） |
| 2.2 | **运镜**：更大气 / 更现代 / 更有激情 | ① 每镜都给速度感：快推（push-in）、横摇（pan）、缩放跨越；② 缩短单镜时长、提高切换节奏（平均 4–5s → 3–4s）；③ 关键节点加**速度斜坡**（ramp：进入慢、出手快）；④ 落版用一次明显的镜头加速 + 光效；⑤ 地图镜重做"飞行"感：沿路线俯冲式推进而非原地缩放 |
| 2.3 | **截图/录屏不带浏览器边框，突出主题** | 采集端就是纯页面截图（Playwright 不拍浏览器边框），但 v2 再进一步：⑥ 隐藏站点自身的顶栏/工具条等无关 chrome（必要时 CSS 注入隐藏）；⑦ 主体内容**满屏铺满**，用 16:9 精确裁切 + 缩放到满幅；⑧ 录屏统一走 **CDP screencast**（帧率可达 30–60fps，无窗口装饰、无鼠标轨迹） |
| 2.4 | **横屏视频里的照片必须是横构图，铺满屏幕** | ⑨ 展示照片时只挑**横构图（landscape）原图**，竖图不进入全屏展示段；⑩ 单张照片展示用**满屏 + 缓推**（Ken Burns）而非带黑边的小图；⑪ 挑选口径：优先选 16:9 / 3:2 风景照、大光比、画面干净的；可从体验账号 3 趟行程（滇藏线 / 独关西赏樱 / 独库公路）的原图里筛 |

## 参考实现要点（v1 已验证可用的技术栈）

- 录屏：CDP `Page.startScreencast`（`quality 92`，JPEG 帧 + ack 回执），脚本 `capture_*.js`
- 截图：Playwright `channel:'chrome'` + `deviceScaleFactor: 2`（产出 3840×2160，够做推镜裁切）
- 合成：`ffmpeg`，`zoompan` 做 Ken Burns / 推摇，`setpts` 调速，`drawtext` 烧字幕
- 音频：`edge-tts`（词级 `WordBoundary` 时间戳 → 字幕时间轴）+ 自合成 BGM，`amix` 混音后 `loudnorm=I=-16`
- 素材源：`https://top001.xin` → `button[data-demo]` 进体验账号（滇藏线行程，1325.8km / 9 城 / 31 媒体）
