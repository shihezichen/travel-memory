# 02 · 口号体系

> 来源：与 DeepSeek 讨论定稿（原始记录见 `原始文案-DeepSeek对话原文.md`）
> 使用口径：所有对外物料（视频落版、海报、落地页、开放平台）**统一从这里取**，不要临时改写。

## 主口号 / 品牌落版

> **把一趟旅行，变成能重新走一遍的记忆。**

## 短口号 / 视频结尾

> **把旅行，重新走一遍。**

## 智能体功能口号

> **问一句，记忆就回来。**

## 副口号

> Travel Memory，按真实路线，串起我的旅行时间记忆；也能被我的智能体随时问起。

## 第一人称增强版

> 把我的那趟旅行，变成能重新走一遍的记忆。问一句，就能回来。

## 官网实际在用的主标题（2026-09-16）

> 把一趟旅行，
> 变成能重新走一遍的记忆

副文案：
> 地图上的真实路线、每个落脚点的照片与心情、一键回放的那一天 —— 以及一个让 AI 直接读懂这些记忆的接口。

顶部小标签条：
> 不碰第三方 · 数据随时导出 · MCP 就绪

## 落版组合（视频片尾推荐排布）

```
旅行记忆 · Travel Memory          ← 小字 + logo
把一趟旅行，
变成能重新走一遍的记忆。           ← 主口号，渐变大字
问一句，记忆就回来。               ← 功能口号，次级
[二维码]  top001.xin               ← 扫码即体验
```

## 语气规范

- **第一人称**（"我"），口语、克制、不说形容词堆砌
- 讲"记忆"和"路"，不讲"云相册""AI 黑科技"
- 三个情感锚点：**模糊 → 找回来 → 被问起**
