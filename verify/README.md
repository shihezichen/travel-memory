# 站长验证文件

这个目录下的 `*.txt` 会被原样挂到站点根目录：

    verify/abc123.txt  ->  https://top001.xin/abc123.txt

微信、Google Search Console、百度站长平台这类「证明你是网站管理员」的
流程，都要求在根目录放一个指定文件名、指定内容的 txt。以前每来一个都要
往 app.py 里加一条路由，现在往这里丢文件就行，不用改代码也不用重启。

规则：
- 文件名只允许字母、数字、下划线、连字符，且必须以 .txt 结尾
- 走 HTTP 和 HTTPS 两条路都能取到（80 端口那个进程单独处理了一次，
  因为有些验证方只发 http 请求且不跟 301）
- 不需要登录，也不受访问口令门禁限制

验证通过后文件可以删，但建议留着 —— 有些平台会定期回查。
